## Diabetes Exploratory Data Analysis

# Overview

This project investigates the diabetes dataset through exploratory data analysis to identify relationships between clinical variables and disease progression.

# Objectives

Explore feature distributions.

Examine feature correlations.

Visualise relationships with the target variable.

# Methods

Histograms

Scatter plots

Correlation heatmap

Summary statistics

# Results

The analysis highlights variables most strongly associated with diabetes progression and demonstrates the importance of exploratory analysis before predictive modelling.

# Technologies

Python • pandas • NumPy • Matplotlib
